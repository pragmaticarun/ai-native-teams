<ul class="lab-meta"><li>⏱ 90 min</li><li>👥 Whole team</li><li>🧰 An assistant with projects/custom instructions, or a coding agent that reads AGENTS.md</li></ul>

## Goal

Write a team instructions file and **measure** whether it improves results on real tasks.

## Steps

1. **Baseline** (15 min). Pick 5 typical tasks (reuse Lab 1 or Lab 2 tasks). Run each in a plain assistant with **no** team instructions. Save outputs.
2. **Harvest knowledge** (20 min). Everyone answers on sticky notes:
   - What does a new teammate get wrong in their first month?
   - What do you keep correcting in AI output?
   - What are our sources of truth?
   - What must never happen?
3. **Draft the file** (20 min). Use the structure from [lesson 2](/ai-native-teams/m03-context/instructions/): who we are, how we work/write, facts and sources of truth, known pitfalls, when unsure. Keep it under ~1 page.
4. **Re-run** (15 min). Load the file as project/custom instructions (or `AGENTS.md` in a repo). Re-run the same 5 tasks.
5. **Compare blind** (15 min). Mix baseline and new outputs, score with the Lab 1 rubric.
6. **Agree ownership** (5 min). Name an owner and a review date. Decide where it lives.

## Deliverable

- Your team instructions file, in the playbook.
- A before/after score table.
- One draft **skill** (lesson 4) for a procedure that didn't belong in the main file.

## Debrief

- Which instruction made the biggest difference?
- Did anything get *worse*? (Over-strict rules often cause this.)
