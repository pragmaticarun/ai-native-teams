Prompting is about the *request*. **Context engineering** is about everything else the model sees: instructions, documents, examples, tool results, memory and history. As models got more capable, the quality of their context became the main thing that determines the quality of their work, especially for agents that run for many steps.

**Time:** ~3 hours · **For:** everyone (lesson 4 is more technical)

## Learning goals

- Explain the context window as a limited budget, and the trade-off between too little and too much context.
- Use the layers of context: system/custom instructions, project knowledge, task context, examples and tool results.
- Write a team instructions file (custom instructions, `AGENTS.md`, project knowledge) that measurably improves results.
- Manage long work with summaries, compaction, memory and fresh sessions.
- Package reusable know-how as **skills** that load only when needed.
