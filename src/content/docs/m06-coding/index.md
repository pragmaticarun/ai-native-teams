Software engineering is where AI-native practice is furthest along, and where the lessons for every other function show up first: **specs matter more, verification matters more, and the bottleneck moves to review.**

**Time:** ~3.5 hours · **For:** engineers (core); PMs and leads (lessons 1 and 3)

## Learning goals

- Place your team on a ladder of AI-assisted engineering, and know what it takes to move up.
- Use the main kinds of coding agents (IDE, terminal, cloud/background, review) for the right jobs.
- Write specs and plans that agents can execute, using spec-driven development.
- Make a repository agent-friendly: instructions, fast verification, clear conventions.
- Keep quality and security high: tests first, risk-based review, and guardrails on agents.
