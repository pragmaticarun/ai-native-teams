An **agent** is a model that can take actions (search, read files, call APIs, edit documents, run code) in a loop until a goal is reached. Agents are where AI moves from *answering* to *doing*, and where both the value and the risk jump.

**Time:** ~3 hours · **For:** everyone (lessons 1, 2, 4 and the no-code lab); builders for lesson 3 in depth

## Learning goals

- Explain tool calling and the agent loop (observe → think → act → repeat) in plain language.
- Know when you need an agent, a fixed workflow, or just a prompt.
- Explain the Model Context Protocol (MCP), what servers and clients are, and how to evaluate an MCP server before connecting it.
- Choose a level of autonomy and human oversight that fits the task's risk.
- Recognise multi-agent patterns and computer-use agents, and their trade-offs.
