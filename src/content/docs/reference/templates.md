## Quick prompt brief

```text
Situation: <who I am, what's going on>
Task: <exactly what to produce>
Context: <documents, data, examples, between clear markers>
Constraints: <must / must not, with reasons>
Output: <format, length, structure>
If anything is unclear or missing, ask me before starting / list gaps at the end.
```
