Everyone should do **Start here, M1, M2, M3, M9 and M13**. Those build the shared vocabulary and the shared plan. Then follow your path.

| Path | Core modules | Recommended | Optional |
|---|---|---|---|
| **Whole team cohort** (default) | All, in order | | |
| **Engineers** | M1–M6, M8, M9 | M10, M11, M13 | M7 |
| **Product managers** | M1–M3, M5, M7, M8, M13 | M4, M6 (lessons 1, 3), M11, M12 | |
| **Designers & researchers** | M1–M3, M7, M9 | M4, M8, M13 | M5 |
| **Operations, support, sales, marketing** | M1–M3, M7, M9, M10 | M4, M5 (lessons 1–3), M13 | M8 |
| **Team leads & managers** | M1–M3, M9–M13 | M6 (lesson 1), M8 | |
| **Executive sprint** (one day) | Start here, M1 lesson 1, M9 overview, M10, M11, M12, M13 capstone | | |

## Suggested 13-week cohort

| Week | Module | Lab |
|---|---|---|
| 1 | Start here + M1 | Model shoot-out on your own tasks |
| 2 | M2 Prompting | Build a team prompt library |
| 3 | M3 Context engineering | Write your team's instructions file |
| 4 | M4 RAG | Knowledge assistant over your docs |
| 5 | M5 Agents & MCP | Connect an agent to a real tool safely |
| 6 | M6 AI-assisted engineering | Ship a change with a coding agent |
| 7 | M7 Workflows | Redesign one end-to-end workflow |
| 8 | M8 Evals | Build an eval set for a real AI use |
| 9 | M9 Safety | Red-team your own assistant |
| 10 | M10 Governance | Draft your AI use policy |
| 11 | M11 Operating model | Map roles, rituals and champions |
| 12 | M12 Value | Define your metrics baseline |
| 13 | M13 Capstone | Present your 90-day plan |
