You don't need to know the maths to use AI well, but you do need accurate **mental models**. Most bad AI experiences (confident nonsense, "it forgot what I said", surprising costs) come from a wrong mental model, not a bad tool.

**Time:** ~2.5 hours (90 min reading, 60 min lab) · **For:** everyone

## Learning goals

By the end of this module you can:

- Explain, in plain language, what a large language model does when it "answers" you.
- Describe tokens, context windows, temperature and why outputs vary between runs.
- Say what reasoning models, multimodal models and small/on-device models are good for.
- Recognise the main failure modes (hallucination, sycophancy, stale knowledge, brittleness) and the standard mitigation for each.
- Pick a model for a task using quality, cost, latency and data constraints, not brand loyalty.
