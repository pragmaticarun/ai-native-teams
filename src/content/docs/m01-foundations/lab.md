<ul class="lab-meta"><li>⏱ 60–90 min</li><li>👥 Whole team, in pairs</li><li>🧰 2–3 approved AI assistants or models</li></ul>

## Goal

Find out which models actually work best for **your** tasks, and practise the evaluation habit you'll use all course.

## Before the session

Each person brings **two real tasks** from the last two weeks, with no confidential data unless your approved tool allows it. Good examples: summarise a long thread, draft a customer reply, explain an error message, turn notes into a plan, extract fields from a document, review a paragraph for clarity.

## Steps

1. **Pick 6–8 tasks** as a team that represent your work. (10 min)
2. **Write a rubric** for each: what does a great answer contain? Agree on 3–4 criteria scored 1–5 (e.g. *correct*, *complete*, *right format*, *usable without edits*). (10 min)
3. **Run each task** with the same prompt on each model, twice. Record time-to-answer and, if visible, token usage. Paste outputs into a shared doc labelled **A/B/C** without model names. (25 min)
4. **Score blind** in pairs. Each pair scores outputs they didn't generate. (15 min)
5. **Reveal and discuss.** (15 min)
   - Where did the models disagree most?
   - Did any model hallucinate? Which failure mode from [lesson 3](/ai-native-teams/m01-foundations/limits/) was it?
   - Did the second run differ from the first? How much?

## Deliverable

Add a **"Which model for what"** table to your team playbook:

| Task type | Recommended model | Why (scores, cost, speed) | Re-check by |
|---|---|---|---|
| | | | |

## Debrief questions

- What surprised you?
- Which task was AI *not* good at, and is that a model problem or a context problem?
- Keep your tasks and rubrics. They're the seed of your first eval set in [Module 8](/ai-native-teams/m08-evals/).
